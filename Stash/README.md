# Stash

Stash 覆写按目标应用分目录存放。

| 项目 | 覆写 | 说明 |
| --- | --- | --- |
| Bilibili | [Bilibili_remove_ads.stoverride](Bilibili/Bilibili_remove_ads.stoverride) | 去广告并优化历史记录加载速度；[详细说明](Bilibili/README.md) |
| Google | [Google.stoverride](Google/Google.stoverride) | 将 Google 搜索与地图从 `.cn` 重定向到 `.com`；[详细说明](Google/README.md) |
| WeatherKit | [iRingo.WeatherKit.stoverride](WeatherKit/iRingo.WeatherKit.stoverride) | WeatherKit 中国 AQI 与数据适配 |

WeatherKit 的跨客户端共用脚本位于 [Scripts/WeatherKit](../Scripts/WeatherKit/)。
