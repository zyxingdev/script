# Google 搜索重定向（Stash）

[Google.stoverride](Google.stoverride) 将 `google.cn` 的搜索与地图请求重定向到对应的 `.com` 域名。

## 订阅

```text
https://raw.githubusercontent.com/zyxingdev/script/main/Stash/Google/Google.stoverride
```

启用覆写前，请确认 Stash 已安装并信任 MitM 证书。如果出现频繁跳转，请停用该覆写。
